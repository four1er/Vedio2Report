# Vedio2Report 项目目标

将有字幕的 YouTube 对话视频转为可阅读的中文分章文章。交付物为 GitHub 仓库、公开访问的 Cloudflare Worker 网址，以及说明实现与取舍的 README。

## 验收场景

1. 输入有字幕的 YouTube 链接并发起生成。应用获取并清洗字幕，向用户标明来源。为字幕获取受限的情况准备一份标明来源的固定示例。
2. 使用 Gemini AI Studio API 生成中文文章，按标题、章节和段落排版。生成过程中逐段或逐字渲染到网页，用户能在请求结束前阅读已输出的内容。
3. 支持可选的自然语言要求，让用户约束任务类型、写作风格、目标受众和内容范围。文章忠于字幕。
4. 每个章节标题旁提供 5W1H 按钮。点击后基于完整视频上下文和该章节生成 Who、What、When、Where、Why、How 六个字段，用统一格式展示。
5. 服务端保存本次生成的上下文。浏览器请求章节总结时只提供文章和章节标识。
6. 用 Node.js / TypeScript 开发和测试，在 Cloudflare Workers 上运行。保持模块边界清晰，凭据由服务端管理。
7. README 说明字幕处理、Gemini 流式输出、自然语言要求、章节总结、部署步骤和主要取舍。

## 提升要求

- 主文章支持选填自然语言要求。读者可以限定任务类型、输出风格、目标受众及内容范围，整理发言时遵循这些限制。
- 文章需要按章节组织，正文在生成过程中逐段可读。每章标题旁的 5W1H 按钮由读者单独触发，只总结选中的章节。
- 章节正文与一至两句阶段小结在同一次主文章请求中流式到达。某一章写完即开放该章的 5W1H，读者展开时，后续章节继续生成。
- 5W1H 结合完整视频字幕、已经保存的文章和所选章节，接口返回六字段 JSON。前端只发送文章和章节 ID，服务端恢复该次生成的上下文。
- 写作要求留空时，按视频时间顺序覆盖开场、中段与收尾。示例提供发布者标注的 12 个话题时间点，章节时间可以跳转回原片。
- GitHub README 说明字幕获取与处理、Gemini 流式输出、自然语言要求、章节级 5W1H，以及主要工程取舍。[实现说明与运行方法](../README.md)

## 逐话题生成的公网验收

2026 年 11 月 20 日，通过桌面 Chromium 在公开写作台提交同一条安德森访谈，并在正文尚未结束时点开第一章的 5W1H。两次请求都使用原片的 2,801 条字幕。下表时间从点击「开始生成」计起，包含 Gemini 的上游等待时间。[打开写作台](https://vedio2report.tf08202000.workers.dev)

| 写作要求 | 首段正文可见 | 首章小结和 5W1H 可用 | 全文结束 | 实际结果 |
| --- | ---: | ---: | ---: | --- |
| 留空，按整场访谈生成 | 52.22 秒 | 52.80 秒 | 5 分 04 秒 | 收到 105 个正文增量。12 章都有小结，章节链接逐一匹配发布者的 12 个时间点。 |
| 写给新入行的产品经理，只讨论 AI 产品定价，写两章问答 | 137.95 秒 | 139.13 秒 | 140.43 秒 | 收到 25 个正文增量。两个章节都包含定价问题、回答和小结。 |

两次都在后续正文仍在生成时发出了首章 5W1H 请求。浏览器只发送带文章和章节 ID 的空正文 POST，页面六个字段与服务器返回的 JSON 逐项一致。自动出现的章末小结没有触发额外的 5W1H 请求。[验收脚本](../scripts/verify-deployment.mjs)

全场成稿在 41:54 写到按用量与按价值定价，1:08:44 写到公众对 AI 就业的担忧，1:15:50 写到安德森如何用投资反馈校准判断。每章是该段的摘要。比如最后的火星问题只出现在成稿标题里，原片中他还回答自己大概不会去。[阅读这次生成的 12 章全文](andreessen-full-interview.md) · [回看原片最后一章](https://www.youtube.com/watch?v=xRh2sVcNXQ8&t=4550s)
